## 摘要
集成外部工具的大型语言模型（LLM）智能体容易受到嵌入环境状态中的间接提示注入攻击。然而，现有研究主要依赖手工实现或复用的环境、基于LLM的随机工具模拟以及预定义的注入位置，限制了更广泛领域内可扩展的安全研究。为弥补这一不足，我们提出ToolHazard，一个可扩展的对抗环境合成框架，能够减少人工工程，并支持通过增加种子领域和算力进行扩展。通过环境模拟器、攻击者智能体和用户模拟器，ToolHazard可合成可执行的有状态环境，发现可行的注入点并生成针对特定环境的攻击载荷，以及构建基于状态的长期任务。基于ToolHazard，我们构建了ToolHazard-Bench，用于在复杂工作流和多样化环境攻击下对智能体进行压力测试。实验揭示了智能体存在显著漏洞，并表明注入时机和位置会影响攻击效果。此外，ToolHazard生成的对齐数据在ToolHazard-Bench和AgentDojo上提升了安全性，同时保持了良性任务效用。

## Abstract
Large language model (LLM) agents integrated with external tools are vulnerable to indirect prompt injections embedded in environmental states. However, existing studies largely rely on manually implemented or reused environments, stochastic LLM-based tool simulation, and predefined injection locations, limiting scalable security research across broader domains. To bridge this gap, we propose **ToolHazard**, a scalable adversarial environment synthesis framework that reduces human engineering and supports expansion with additional seed domains and compute. Through an Environment Simulator, an Attacker Agent, and a User Simulator, ToolHazard synthesizes executable stateful environments, discovers viable injection points and generates environment-specific payloads, and constructs state-grounded long-horizon tasks. Based on ToolHazard, we build **ToolHazard-Bench** for stress-testing agents under complex workflows and diverse environmental attacks. Experiments reveal substantial agent vulnerabilities and show that injection timing and placement affect attack effectiveness. Moreover, ToolHazard-generated alignment data improves security on both ToolHazard-Bench and AgentDojo while preserving benign task utility.

## 2. 方法论

ToolHazard 由三个核心模块组成：

- **环境模拟器（Environment Simulator）**
  - **环境蓝图规划**：从种子任务数据推断环境类型、状态表示、实体模式、约束规则和可执行操作。
  - **可执行程序构建**：将蓝图转换为面向对象的 Python 类，实体为属性、工具为方法，并生成标准化 API 文档。
  - **自动质量检查**：采用双智能体验证管道（Testing Agent 与 Checking Agent），通过交互测试和规则一致性检查过滤低质量环境。
- **用户模拟器（User Simulator）**
  - **状态初始化**：基于环境骨架和约束生成初始环境状态。
  - **用户任务生成**：基于初始化状态、工具集和约束合成长期、状态grounded 的良性任务。
- **攻击者智能体（Attacker Agent）**
  - **环境攻击点发现**：包括可注入属性识别（区分自由文本字段与受限字段）、操作读写分析（构建操作-状态依赖图）、攻击点匹配（保留同时具备读路径和写路径的属性）。
  - **对抗注入流水线**：基于良性执行轨迹进行攻击点过滤（轨迹对齐，优先选择在轨迹中更早被读取的注入点），然后采用计划-执行框架生成载荷并通过写操作注入环境。
- **验证函数生成**：将任务分解为多个可验证条件，为每个条件生成基于最终环境状态的验证函数，得分通过 `Score = (1/K) Σ 1[f_ck(S_final)=1]` 计算，不依赖具体执行轨迹。

基于该框架构建：

- **ToolHazard-Bench**：28 个测试环境、512 个工具、87 个长期任务，平均执行步数 15.56。
- **ToolHazard-Align**：60 个训练环境，生成 1,040 个有效对抗样本（329 个用于 RL，711 个用于 SFT）。

## 3. 实验设计

- **评估基准**：ToolHazard-Bench，包含六种预定义注入策略：basic combined、important-template、multi-turn、decision hijacking、reasoning criteria、tool selection。
- **评估对象**：GPT-5、GPT-4.1、Gemini-3.1-pro-preview、Gemini-2.5-pro、DeepSeek-V3.2、Qwen3-8B/4B 共 7 个模型，均使用 ReAct 框架。
- **评估指标**：良性任务完成率（BR）和攻击成功率（ASR），均由程序化验证函数计算，不依赖 LLM 评判。
- **对齐实验**：对 Qwen3-4B 和 Qwen3-8B 进行 SFT + GRPO 强化学习，在 ToolHazard-Bench 和 AgentDojo 上评估，比较原始模型、SFT、SFT+RL、ToolHazard-Align 四种设置。
- **分析实验**：
  - 注入时机：top-1（最早可达点）、top-2、random；
  - 注入放置：top-1（最后一个字段）、top-2、random；

  - 跨攻击策略泛化：训练三种攻击策略，测试三种未见策略。

## 6. 主要结论与发现

- **LLM 智能体仍高度易受环境提示注入攻击**：几乎所有模型在对抗环境下 ASR 较高。GPT-5 有 4 种攻击策略 ASR 超过 40%；DeepSeek-V3.2 良性任务完成率最高但最易受攻击；Qwen3-4B 因指令遵循能力弱而受影响较小，暗示更强模型可能更易受环境提示注入影响。
- **新兴攻击策略带来更大挑战**：decision hijacking、tool selection、reasoning criteria 等策略在多模型上持续取得高 ASR，暴露当前安全对齐的不足。
- **注入时机影响攻击效果**：注入指令在轨迹中越早被遇到，ASR 越高。
- **注入放置影响攻击效果**：注入内容位于工具输出字段的尾部时 ASR 更高，表明 LLM 智能体对尾端内容存在位置偏差。
- **输出格式影响攻击效果**：自由文本输出比 JSON/YAML 结构化输出的 ASR 显著更高，结构化格式提供部分语义隔离。
- **对抗环境降低良性任务能力**：注入攻击不仅诱导不安全行为，还系统性损害智能体完成正常任务的能力。
- **对齐有效**：ToolHazard-Align 在 ToolHazard-Bench 和 AgentDojo 上均显著降低 ASR、提升 BR，且未观察到过度拒绝，并能在跨攻击策略和跨基准上泛化。

## 7. 优点

- **高度可扩展**：自动合成可执行有状态环境、发现注入点、生成任务和攻击，减少人工工程，支持从新种子领域持续扩展。
- **攻击点发现而非预定义**：主动识别环境中具备读写路径的可注入属性，并沿轨迹对齐筛选，提升攻击可达性。
- **程序化验证**：基于最终环境状态的检查函数计算 BR/ASR，避免 LLM 评判的随机性，支持稳健、可复现的评估。
- **开源与透明**：提供完整开源包、提示模板、成本分析，可复现性强。
- **兼具评估与对齐功能**：不仅构建基准，还生成对齐训练数据，证明数据驱动安全增强的可行性。
- **多维度分析**：对注入时机、放置、输出格式和跨攻击泛化进行系统实验，提供有价值的实证见解。

## 8. 不足与局限

- **环境真实性**：合成环境与真实企业系统仍有差距，不能完全复现专有实现、部署特定交互和长尾故障模式。
