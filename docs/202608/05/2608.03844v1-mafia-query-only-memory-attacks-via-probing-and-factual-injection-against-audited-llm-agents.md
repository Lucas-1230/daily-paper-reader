## 摘要
记忆增强的LLM智能体依赖丰富的上下文进行长期推理和行动，但其内存模块暴露了恶意记录的持续攻击面，使得研究内存投毒威胁势在必行。然而，现有的仅查询攻击往往在两种现实且普遍的设置中失效：大规模良性内存池和主动输入审计。因此，当前的方法在面对高检索竞争性和严格语义检查的双重挑战时力有不逮。为了克服这些限制，我们提出了MAFIA，一种针对审计的通过探测和事实注入的仅查询内存攻击框架，专为这种扩展的威胁模型设计。具体来说，MAFIA引入：(1) 一种放置策略，通过内存探测、预算分配和调度确保检索竞争性注入；(2) 一种有效载荷设计，利用紧凑的事实伪装绕过审计，在保持高语义相似度的同时保留恶意效果。广泛的评估表明，MAFIA实现了高达90.7%的攻击成功率，同时将审计检测从峰值83.3%压制到最高7.4%，暴露了智能体内存系统中的关键漏洞。代码将在https://github.com/JiamingChen1234/MAFIA上公开提供。

## Abstract
Memory-augmented LLM agents rely on rich context for long-horizon reasoning and acting, yet their memory modules expose a persistent attack surface for malicious records, making the study of memory poisoning threats imperative. However, existing query-only attacks often fail to remain effective in two realistic and prevalent settings: large-scale benign memory pools and active input auditing. Consequently, current approaches fall short when facing the dual challenges of high retrieval competitiveness and rigorous semantic checks. To overcome these limitations, we propose MAFIA, a query-only Memory Attack framework via probing and Factual Injection against Audit, tailored to this extended threat model. Specifically, MAFIA introduces: (1) a placement strategy that ensures retrieval-competitive injection via memory probing, budget allocation, and scheduling; and (2) a payload design that bypasses audits using compact factual cloaks, preserving malicious effects while maintaining high semantic similarity. Extensive evaluations reveal that MAFIA achieves up to a 90.7% attack success rate while suppressing audit detection from a peak of 83.3% to at most 7.4%, exposing critical vulnerabilities across agentic memory systems. Code will be made publicly available at https://github.com/JiamingChen1234/MAFIA.

### 2. 论文提出的方法论
MAFIA 框架由两阶段协同工作：**放置策略**（解决“在哪里注入”）和**紧凑事实伪装载荷**（解决“如何注入而不被发现”）。

#### 2.1 放置策略：内存探测与预算分配
- **核心思想**：利用良性记忆池反映历史查询分布的特性，通过黑盒探测获取任务语义空间样本，从而将有限攻击预算分配到未来受害查询更可能检索到的区域。
- **关键技术步骤**：
  - **内存探测**：基于公开领域模式合成种子查询，发送给智能体并利用响应中暴露的历史问题字段（不直接访问记忆库），汇总为替代池 `D`。
  - **聚类与预算分配**：对 `D` 中的问题进行凝聚聚类（余弦相似度，平均链接），使用“规模排序轮询”策略分配攻击查询模板：优先选取大簇代表高密度区域，同时保证跨区域覆盖；每簇内选质心最近的问题作为基模板。
  - **注入调度**：按簇规模**升序**（小簇优先）依次注入，以先在竞争弱的区域建立目标导向记录，为后续大簇注入提供检索增强。
- **整体流程**：探头合成 → 黑盒交互收集问题 → 聚类并选出 `b` 个基模板 → 捆绑受害实体 `V` → 按升序调度注入。

#### 2.2 有效载荷：紧凑事实伪装
- **核心思想**：用简短、声明式的数据库事实注释取代显式操控指令，使载荷既在嵌入空间中贴近受害查询，又避免触发审计器。
- **关键技术形式**：`“(→ 目标实体 in this DB)”` 型括号注释。
  - 括号将伪装成补充模式注释，非行为指令；
  - 箭头编码实体替换但无助动词等审计敏感特征；
  - “in this DB”将其提升为数据局部事实，智能体将其视为证据并在后续推理中采纳。
  - 紧凑性使基查询的表面形式主导语义，多条此类记忆因此落入受害查询同一邻域，持久占据 top-K。
- **绕过审计**：载荷不含强制性提示，仅表现为一条附加数据库注释，LLM 审计器将其判定为安全。

### 6. 论文的主要结论与发现

- **攻击有效性**：MAFIA 在所有场景下均实现高 ASR（最高 90.7%），同时将单条记录审计检测率从 MINJA 的 68.4–83.3% 大幅压至 0.0–7.4%，审计过滤后 MINJA 几乎失效，而 MAFIA 保持强势。
- **对抗审计**：低误报的语义审计器无法可靠检测事实伪装；高检测率审计器则伴随极高误报（例如 44.9%），不实用。

- **内存侧防御局限**：后检索一致性检查（A-MemGuard）虽能检出部分毒化记录，但伴随高达 44.9% 的良性误报，难以实际部署。
- **关键洞察**：永久性和大规模良性池虽是防御难点，但也可被攻击者利用——探测良性分布并策略性投放，可将良性记忆转化为攻击持久化的帮手。

### 7. 优点

- **威胁模型贴近现实**：首次在仅查询攻击中同时考虑大规模记忆检索竞争和主动输入审计，弥补了现有研究的盲区。

### 8. 不足与局限

- **记忆架构范围有限**：仅聚焦 RAG 式记忆，未涉及图记忆、层次记忆等新型长期记忆系统，需针对这些架构开发特定攻击模型。
- **防御覆盖不完整**：未评估基于溯源、访问控制、信息流控制等更底层的系统级防御，其有效性有待进一步验证。
- **检索器边界**：纯字符级距离（如编辑距离）下攻击基本失效，暗示方法对检索机制类型敏感。
- **潜在误报代价**：虽展示了审计绕过效果，但未讨论部署环境中极高误报审计器可能引发的系统可用性问题（仅作为防御评估）。
- **场景通用性**：虽然测试了四个常见智能体应用，但真实部署的交互模式可能更复杂，攻击的迁移性需更多实践检验。
- **探针成本与可行性**：假设攻击者可在黑盒下通过响应获取历史问题字段，这在某些严格输出过滤的智能体中可能受限。
