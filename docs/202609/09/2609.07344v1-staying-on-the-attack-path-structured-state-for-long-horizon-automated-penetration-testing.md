## 摘要
基于大语言模型（LLM）的智能体正越来越多地应用于漏洞发现和自动化渗透测试等网络安全任务。然而，在长时程安全任务中，这类智能体仍受限于上下文遗忘与意图漂移：随着交互持续，早期关键事实和因果推理链会丢失，智能体陷入无目的、重复的探索。本文提出 Intentest，一种意图图引导的自动化渗透测试智能体，将长时程状态从 LLM 的上下文窗口外化到持久化的事实-意图有向无环图（DAG）上，从而大幅减少无效转移。我们在 Web 应用自动化渗透测试这一具有代表性的网络安全长尾任务上评估了 Intentest。在该 DAG 中，经过验证的网络状态被存储为不可变的事实节点，探索方向被约束为受前置事实限定的意图边。系统采用三层架构：事实-意图映射层维护全局状态，任务调度与分配层通过两阶段降级恢复和多维自适应负载均衡保证执行稳定性，意图检索与预测层通过自顶向下的五阶段过滤算法提供战术先验。在覆盖三个难度级别、十多种漏洞类型的真实 CTF 赛题基准上，Intentest 的总体成功率达到 88.2%，在高难度任务上成功率为 75.0%，分别比基线提高约 44 个和 50 个百分点。消融实验进一步表明，意图检索与预测在不改变可解任务集合的情况下，将成功的中等和高难度任务的平均轮次分别减少约 33% 和 48%。

## Abstract
Large language model (LLM) based agents are increasingly applied to cybersecurity tasks such as vulnerability discovery and automated penetration testing. On long-horizon security tasks, however, such agents remain limited by context forgetting and intent drift: early critical facts and causal reasoning chains are lost over extended interactions, and the agent falls into aimless, repetitive exploration. This paper proposes Intentest, an intent-graph-guided automated penetration testing agent that externalizes long-horizon state from the LLM's context window onto a persistent fact-intent directed acyclic graph (DAG), thereby substantially reducing invalid transitions. We evaluate Intentest on automated penetration testing of web applications, a representative long-tail task in cybersecurity. In the DAG, verified network states are stored as immutable fact nodes, and exploration directions are constrained as intent edges bounded by predecessor facts. The system adopts a three-layer architecture, in which the fact-intent mapping layer maintains the global state, the task scheduling and allocation layer ensures execution stability through two-phase degradation recovery and multi-dimensional adaptive load balancing, and the intent retrieval and prediction layer provides tactical priors through a top-down five-stage filtering algorithm. On a benchmark of real CTF challenges covering more than ten vulnerability types across three difficulty levels, Intentest achieves an overall success rate of 88.2% and a success rate of 75.0% on hard tasks, improving over the baseline by approximately 44 and 50 percentage points. Ablation experiments further show that the intent retrieval and prediction reduce the average number of rounds on successful medium and hard tasks by about 33% and 48%, respectively, without changing the set of solvable tasks.

  - **上下文遗忘**：早期获得的关键事实（如某内网网段、数据库凭证）在长交互序列中被截断、稀释或遗漏。
  - **意图漂移**：代理逐渐偏离初始目标，陷入无目的、重复的探索，执行大量无效操作。

## 2. 论文提出的方法论

Intentest 采用三层架构，核心是 **Fact-Intent DAG** 作为全局状态黑板。

### 2.1 事实-意图映射层（Fact-Intent Mapping Layer）

- 基于 BDI（Belief-Desire-Intention）框架，将渗透测试建模为：
  - **Goal**：宏观静态最终状态（如获得域控权限）。
  - **Action**：底层引擎直接执行的命令（如端口扫描）。
  - **Intent**：连接宏观目标与具体动作的战术承诺。
- **Fact-Intent DAG 定义**：
  - **事实节点（Fact）**：经过验证的不可变网络状态。
  - **意图节点（Intent）**：探索方向，受前置事实约束。
  - 边分为两类：事实 → 意图（前置触发边）和 意图 → 事实（成功验证后产生新事实）。
  - 任意路径交替经过事实与意图节点，且无环。
- **状态机**：意图节点具有四状态有限状态机（FSM）：
  - `CREATED`（生成）、`CLAIMED`（被认领）、`CONCLUDED`（漏洞验证成功）、`COMPLETED`（命中目标）。
  - 超时回收会将 `CLAIMED` 重置为 `CREATED`。
- **持久化存储**：系统维护六张核心表（project、fact、intent、intent-source、prompt、scope），支持异步、间接协作，避免多代理之间的广播风暴。

### 2.2 任务调度与分配层（Task Scheduling and Allocation Layer）

- **三类标准化任务**：
  - **Bootstrap**：项目初始化时进行广谱扫描，生成首批攻击载荷。
  - **Explore**：单步验证未验证的意图边，优先级最高。
  - **Reason**：全局逻辑规划，受单项目互斥锁约束。
- **多维自适应负载均衡**（Algorithm 1）：依次执行协议一致性、容量安全、健康探测、优先级权重、活跃负载和随机抖动共六步过滤与选择。
- **两阶段降级恢复**：Explore/Bootstrap 任务主超时 180 秒后不直接销毁容器，而是触发 90 秒降级阶段，强制停止网络探测、从 stdout/stderr 日志中回收部分事实并写回图。
- **安全防护**：
  - 结构前置条件验证：任何意图必须由已验证事实节点触发，否则无法写入意图表。
  - 容器级隔离：探测与解释脚本运行在独立 Docker 容器，检测到停滞或未经验证的命令立即终止。

### 2.3 意图检索与预测层（Intent Retrieval and Prediction Layer）

- **三类图**：
  - 离线**意图图**：从威胁情报、演练文档中提取，映射到 MITRE ATT&CK，包含负样本错误路径。
  - 在线**攻击图**：实时记录已验证事实与已执行攻击步骤。
  - **合并图**：融合两者，为当前环境提供战术推荐。
- **自顶向下五阶段过滤算法**（Algorithm 2）：
  1. **高维语义嵌入初筛**：使用 Qwen3-Embedding-4B 对当前图节点属性向量化，用余弦相似度选出 Top-k 候选意图簇。
  2. **子图同构验证**：对候选意图的前驱子图与历史威胁图做子图同构匹配，减少纯单词重叠导致的因果幻觉。
  3. **降级模糊统计推断**：当同构失败时，基于 Jaccard 系数做模糊图相似匹配，容忍局部拓扑缺失。
  4. **战略意图对齐**：将候选序列与用户授权目标及主漏洞链对齐，剪除偏离目标的分支。
  5. **LLM 启发式推理**：前四阶段无匹配时，注入降维环境日志与残差拓扑，由 LLM 进行启发式推理。
- **约束**：所有五阶段输出都必须通过 DAG 前置条件验证，未基于已验证事实的建议被拒绝执行。
- **异步意图桥注入**（Algorithm 3）：在成功 Explore 任务写入新事实后触发，相似度阈值 0.3，注入精简后的三段式上下文（推荐战术动作、支持证据链、当前项目上下文），并去除相似度分数、来源名称等元数据。

## 6. 论文的主要结论与发现

- **RQ1（有效性）**：Intentest 在三个难度级别成功率均最高，总体 88.2%，高难度 75.0%；相比 VulnBot 分别提升约 44 和 50 个百分点，所有总体差异均显著。

- **RQ3（意图模块贡献）**：消融显示禁用意图检索与预测后，可解任务集合不变，但成功任务平均轮次从 11 降到 7，中等任务减少约 33%，高难度任务减少约 48%。说明 **DAG 决定可解性，意图模块决定效率**。
- **失败模式对比**：VulnBot 失败主要是推理与状态缺陷（过早声明成功、角色/状态混淆、长输出中漏掉 flag、僵化剧本重复执行）；Intentest 失败主要发生在专家级多漏洞复合任务或最后一步提权，而非状态或推理缺陷。

## 7. 优点

- **结构化状态管理**：将长期状态从 LLM 上下文外化到持久图数据库，有效缓解上下文遗忘与意图漂移。
- **三层架构设计清晰**：事实-意图映射、任务调度分配、意图检索预测各司其职，模块边界明确。
- **五阶段过滤算法**：渐进式地从语义初筛到子图同构再到模糊匹配，最后才交给 LLM 启发式推理，显著减少因果幻觉和噪声。
- **鲁棒的调度与恢复**：两阶段降级恢复在任务超时后仍可从残留日志中回收部分事实，避免全量丢失；多维负载均衡防止计算过载。
- **安全机制完善**：DAG 前置条件验证 + 容器隔离，从结构上阻止未经验证的注入式指令获得执行授权。
- **实验设计有一定说服力**：统一模型、统计检验、消融实验、案例定性分析相结合，证据链较完整。
