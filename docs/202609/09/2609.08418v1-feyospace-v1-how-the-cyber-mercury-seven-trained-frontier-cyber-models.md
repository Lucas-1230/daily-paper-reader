## 摘要
训练具备能力的网络智能体通常主要被视为模型规模问题，然而开放权重后训练更直接地受到可执行环境成本、可靠多轮监督以及获取强大教师模型的制约。我们提出了一个以数据为中心的框架，通过五个互补系统解决这些瓶颈：Choulea 分析隐藏的推理签名，SkyReal 降低教师采样成本，Hongzwang 绕过教师执行上的 API 限制，PSBreakup 恢复因模型合并而削弱的能力，Kreator 将专家干预转化为可训练的推理。我们的数据引擎构建了可重置的编码、漏洞、CTF、内核历史、完整漏洞利用、固件和设备支持环境。候选轨迹只有在执行验证和证据审计后才会被保留，最终得到 164,269 条轨迹用于长上下文监督微调。三个检查点在完整 CyberGym 套件上平均比初始模型提升 23.76%，在汇总的 CTF 套件上提升 10.49%。截至 2026 年 9 月 1 日，Feyospace-s1 的验证成功率达到 63.24%，在官方 CyberGym 排行榜上排名第 10，而三个检查点在同等参数规模的模型中均排名第 1。据我们所知，这是首次端到端证明，一个七人独立团队能够训练出具有领先智能体网络能力的开放权重模型。

## Abstract
Training capable cyber agents is often treated primarily as a problem of model scale, yet open-weight post-training is constrained more directly by the cost of executable environments, reliable multi-turn supervision, and access to strong teachers. We present a data-centric framework that addresses these bottlenecks through five complementary systems: Choulea analyzes hidden reasoning signatures, SkyReal reduces teacher-sampling cost, Hongzwang bypasses API restrictions on teacher execution, PSBreakup restores capabilities weakened by model merging, and Kreator converts expert interventions into trainable reasoning. Our data engine constructs resettable coding, vulnerability, CTF, kernel-history, full-exploit, firmware, and device-backed environments. Candidate trajectories are retained only after execution verification and evidence auditing, yielding 164,269 trajectories for long-context supervised fine-tuning. The three checkpoints improve over their starting models by an average of 23.76% on the full CyberGym suite and 10.49% across the pooled CTF suites. As of September 1, 2026, Feyospace-s1 achieves a verified success rate of 63.24% and ranks 10th on the official CyberGym leaderboard, while all three checkpoints rank 1st among models at comparable parameter scales. To our knowledge, this is the first end-to-end demonstration that a seven-person independent team can train open-weight models with leading agentic cyber capability.

## 2. 论文提出的方法论

### 2.1 五个监督与能力技术

论文提出五个互补系统（其中两个最终未用于训练管道）：

- **Choulea（签名黑客）**
  - 分析并恢复专有模型返回的**加密推理块**中的隐藏推理签名；
  - 定义“原子操作”和“原子操作组合”来描述模型的“认知方言”；
  - 用于研究推理保真度，但**未作为 SFT 训练目标**，仅作为观测证据；
  - 经历了五代技术演进，恢复率在防御更新前达 92.8%，之后显著下降。

- **SkyReal（杠杆账户）**
  - 通过全球灰市账户供应链，实现低价获取强教师模型 API 访问；
  - 系统平均杠杆达约 **273×**，即 1 美元可获取名义价值约 273 美元的 token；
  - **最终未用于训练管道**，因为不满足内部要求。

- **Hongzwang（越狱技术）**
  - 针对 CVE 分析、漏洞环境构建、模型训练开发等工作负载，绕过闭源模型 API 限制；
  - 包含 7 种变异策略（任务分解、措辞变异、角色框架、上下文排序、工具调用结构化、执行强度调整、重命名与竞争挑战）；
  - 采用固定工作流：策略注入、并发试探、会话修复、切换重试；
  - **最终未用于训练管道**，因为不满足内部要求。

- **PSBreakup（模型合并逆转）**
  - 针对开放权重模型在合并或后训练中被刻意削弱的网络安全能力，进行白盒蒸馏恢复；
  - 使用双向干扰探针划分“有效域”，构建提示条件下的教师分布；
  - 目标函数为 token 级逆向 KL 蒸馏：目标域使用恢复提示教师，保留域使用正向教师，并以随机锚教师防止漂移；
  - 恢复后模型可作为网络安全轨迹的 rollout 教师。

- **Kreator（专家干预内化）**
  - 在教师模型无法独立解决 EXP（漏洞利用）任务时，由人类专家插入关键提示；
  - 教师模型将专家提示改写为**第一人称原生推理**，并去除外部依赖；
  - 只在轨迹通过执行验证后才保留；
  - 在内部 55 个 V8 环境测试中，教师自改写方案解决了 32/55 个 exploit。

### 2.2 环境与数据引擎

数据引擎构建了可重置环境，覆盖：

- **基础编码**：3,751 个多语言仓库，处理 27,502 个实例，79.0% 验证通过；
- **Category A**：从 343,214 条 CVE 记录构建 69,854 个漏洞复现环境；
- **Category B**：9,312 个 CTF 挑战环境；
- **Category C**：从 428,000 个内核提交中挖掘 12,993 个内核历史漏洞环境；
- **Category D**：从 A–C 中重建 1,601 个完整 EXP 环境；
- **硬件**：1,003 个固件再托管 + 374 个物理设备环境，共 1,377 个。

所有候选轨迹经历：

- **执行验证**：PoC/flag/EXP 必须在干净容器中可重复验证；
- **四层证据审计**：
  1. 确定性证据筛查；
  2. 泄漏与奖励黑客审计；
  3. 轨迹真实性与能力映射；
  4. 高阶行为分析（如评估意识、异常自我提醒等）。
- 成功轨迹接受率 85%，9% 进入人工复核，6% 拒绝。

最终得到 **164,269 条审计轨迹**用于 SFT。

### 2.3 监督微调与训练配置

- **模型**：Qwen3.6-35B-A3B、Qwen3.8-27B、Qwen3.5-122B-A10B；
- **训练方式**：仅 SFT，无 RL 阶段；
- **损失函数**：对每个轨迹中的 token 加权：
  - 最终答案和助手工具调用 token 权重 **1**；
  - 推理 token 权重 **0.8**；
  - 系统/用户提示、工具响应、环境观察等**掩码**；
  - 按有效监督 token 数归一化，防止长轨迹主导更新；
- **长上下文打包**：多轨迹打包到 262,144 token 序列，使用文档级 block-diagonal 因果注意力掩码，避免跨轨迹泄漏；
- **优化**：BF16、FlashAttention 2、Transformer Engine 融合交叉熵、Megatron distributed Adam、3 个 epoch、全局 batch size 8、峰值学习率 1e-5 余弦衰减；
- 训练目标强调教师-学生推理兼容性：详细推理轨迹的教师适合小模型，而简洁的高能力教师轨迹难转移到 300B 以下学生。
