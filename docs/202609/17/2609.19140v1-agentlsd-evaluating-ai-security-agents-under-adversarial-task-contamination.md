## 摘要
用于安全领域的AI智能体会检查网页、源代码、日志、配置文件和命令输出。这些环境可能包含影响智能体行为的欺骗性工件。我们将此称为对抗性任务污染。提示注入依赖攻击者提供的指令，而任务污染还包括非指令性证据，例如伪造结果和诱饵端点。我们提出了AgentLSD，一个用于研究对抗性任务污染的受控框架。AgentLSD以夺旗（CTF）挑战作为实验环境。我们在保留既定CTF解决方案的同时，注入陷阱工件，例如伪造flag、误导性提示、诱饵端点和隐藏线索。该框架支持成对的干净与陷阱增强实验，并具备确定性陷阱生成、运行时注入、遥测和投递验证功能。我们在11个Web CTF挑战上评估了六个模型。在干净条件下，智能体捕获了41%的flag，且没有模型能够解决所有挑战。随后我们测量了任务污染的影响。即使智能体仍然能恢复flag，陷阱也会增加回合数（+20）和推理token数（+2k）。对解题率的影响则更具异质性：一些模型-挑战组合几乎不受影响，而另一些则会跟随诱饵或提交错误的flag。这些结果表明，干净的CTF表现低估了智能体对欺骗性任务证据的脆弱性。AgentLSD隔离了这一效应，并为研究它提供了可复现的基准。我们发布了该框架、配置、陷阱规范和原始轨迹。

## Abstract
AI agents for security inspect web pages, source code, logs, configuration files, and command outputs. These environments may contain deceptive artifacts that influence the agent's behavior. We call this adversarial task contamination. Whereas prompt injection relies on attacker-supplied instructions, task contamination also includes non-instructional evidence, such as fake results and decoy endpoints. We present AgentLSD, a controlled framework for studying adversarial task contamination. AgentLSD uses Capture the Flag (CTF) challenges as its experimental environment. We inject trap artifacts, such as fake flags, misleading hints, decoy endpoints, and hidden cues, while preserving the intended CTF solution. The framework supports paired clean and trap-augmented experiments with deterministic trap generation, runtime injection, telemetry, and delivery verification. We evaluate six models on 11 web CTF challenges. In the clean condition, agents capture 41% of the flags, and no model solves every challenge. We then measure the impact of task contamination. Even when the agent still recovers the flag, traps increase the number of turns (+20) and reasoning tokens (+2k). Solve-rate effects are more heterogeneous, as some model-challenge pairs are largely unaffected while others follow decoys or submit wrong flags. These results show that clean CTF performance understates vulnerability to deceptive task evidence. AgentLSD isolates this effect and provides a reproducible benchmark for studying it. We release the framework, configurations, trap specifications, and raw traces.

## 1. 论文的核心问题与整体含义

- 论文研究 **AI 安全代理在对抗性环境中的鲁棒性**，提出“**对抗性任务污染**”（adversarial task contamination）这一威胁模型。
- 与传统的“提示注入”不同，任务污染不限于攻击者提供的指令，还包括**非指令性欺骗证据**：假 flag、误导性提示、诱饵端点、隐藏线索、伪造验证结果等。
- 核心问题：安全代理在执行任务时会检查攻击者可控的网页、源码、日志等，这些内容可能误导代理改变行为、浪费资源或提交错误结果。
- 整体含义：现有评测多关注提示注入或纯任务难度，**低估了欺骗性环境证据对代理脆弱性的影响**。论文旨在通过可控实验隔离并量化这一效应。

## 2. 论文提出的方法论

- 提出 **AgentLSD** 框架，一个用于研究对抗性任务污染的受控实验平台。
- **核心思想**：在保持 CTF 挑战原解决方案、漏洞路径和 flag 校验逻辑不变的前提下，向环境中注入受控的陷阱工件，从而形成“干净—陷阱”配对实验。
- **关键技术细节**：
  - **陷阱规范**：使用 YAML 原语（primitive）描述陷阱家族，包含感知通道、目标对象、负载模板、放置位置、随机化参数、可选仪表化等。通过确定性生成器将模板解析为具体实例（如将 `{{authority_phrase}}` 和 `{{dynamic_decoy_path}}` 解析为具体短语和路径）。
  - **运行时注入**：Flask 中间件在挑战正常 HTTP 响应之后修改 HTML（DOM 陷阱），可插入可见文本、隐藏节点、注释、元标签、无障碍属性等；同时支持动态陷阱路由（如兔子洞路由、假目标端点）。
  - **遥测与验证**：记录与陷阱和蜜标的交互（请求、渲染、蜜标命中、兔子洞跳转等）；使用 DOM 验证器确认陷阱成功投递。
  - **陷阱分类**：定义了 5 类失败意图：
    - **目标劫持**（goal hijack）：将代理目标替换为诱饵；
    - **虚假权威**（false authority）：让不实提示看起来有权威；
    - **虚假验证**（false validation）：让诱饵看起来已被验证或成功；
    - **探索诱饵**（exploration bait）：诱导代理访问无关端点或文件；
    - **时间消耗**（time sink）：引导代理做低价值工作。
- 无复杂公式；核心是**实验控制与配对比较**，通过同一挑战的干净与陷阱条件差异归因于陷阱效应。

## 3. 实验设计

- **数据集/场景**：自建 11 个 Flask Web CTF 挑战，覆盖 7 类漏洞（命令注入、路径遍历、竞态条件、SQL 注入、SSRF、模板注入、XXE）。挑战在评估前未公开，避免记忆偏差。
- **Benchmark**：AgentLSD 本身构成基准；没有与现有基准直接对比，而是与干净条件（无陷阱）进行配对比较。
- **模型**：6 个模型——5 个本地部署（Gemma-4 31B、DeepSeek-V4 Flash、GPT-OSS 120B、Qwen3-Coder-Next、Mistral Small 4）和 1 个托管前沿模型（GPT-5）。
- **实验阶段**：
  - **基线阶段**：所有 5 个本地模型 × 11 挑战 × 2 种提示（默认、方法学）= 550 次干净试验；GPT-5 默认提示 55 次，共 605 次。

## 6. 论文的主要结论与发现

- **干净条件下**：智能体总体 flag 捕获率约 41%，没有任何模型解决全部挑战；最强本地模型与 GPT-5 接近，说明语料未饱和、难度适中。
- **陷阱效应**：
  - **主要代价是努力增加**：即使仍能成功，陷阱平均增加约 20 个交互回合和 2000 推理 token。
  - **解决率影响呈异质性**：部分模型-挑战组合几乎不受影响，另一些完全丢失干净条件下的成功。
- **陷阱家族差异**：
  - **目标劫持和探索诱饵**导致最大解决率下降；
  - 所有陷阱家族都增加努力，即使不改变解决结果。
- **陷阱交互**：蜜标遥测显示，代理接触诱饵很常见（39–57% 的陷阱运行），但关键区别在于**是否能够及时脱离**：DeepSeek 接触后大多恢复，GPT-OSS 接触后解决率从 65% 暴跌至 28%，且逗留步数更长。
- 结论：**干净 CTF 性能低估了对欺骗性任务证据的脆弱性**，任务污染是一个独立的鲁棒性问题。

## 7. 优点

- **实验控制严格**：配对干净—陷阱设计、固定任务语义、同支架、同温度；只改变环境工件，能有效归因。
- **陷阱分类清晰**：按失败意图划分五类，结合感知通道、目标对象和仪表化标签，便于分析哪种机制更有效。
