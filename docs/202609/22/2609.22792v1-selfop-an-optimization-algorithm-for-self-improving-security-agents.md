## 摘要
LLM 智能体正越来越多地用于安全任务：漏洞发现、漏洞利用复现和补丁生成。在模型层面改进它们需要专家演示或可计算奖励，而安全任务很少能提供这些：轨迹成本高昂，失败难以诊断，奖励稀疏且不可计算。因此，努力转向执行框架和上下文，但手动调优需要任务特定的专业知识且扩展性差，而自动化方法依赖稀缺的真实标注、更强的优化器模型，或退化为昂贵试错的盲目提议-评估循环。我们提出 SelfOp，一种自动改进冻结的安全智能体任务上下文（指令、技能和参考文档）的算法，而不修改其执行框架和模型权重。SelfOp 将上下文优化视为受链式法则启发的文本梯度下降：从单个实例的结果出发，将误差信号通过评估器、智能体轨迹和塑造其行为的上下文构件反向传播，产生每个实例的文本梯度。梯度通过聚类、排序和过滤在实例间累积，并且仅在跨实例一致时提交。收敛检测器监控梯度信号本身，一旦上下文吸收了训练数据中可泛化的信息便停止，无需留出验证数据。我们在 CyberGym（一个真实漏洞复现任务基准）上评估 SelfOp。在少于 200 个训练示例的情况下，SelfOp 为 GPT-5.4-mini（搭配 Codex）带来 17 个百分点的自我提升，足以超过前沿 GPT-5.4 基线 6 个百分点；为 GPT-5.4 本身带来 18.5 个百分点的自我提升。优化后的技能还能跨模型迁移，表明 SelfOp 优化的技能学到的是可泛化的任务知识，而非模型特定的模式。

## Abstract
LLM agents are increasingly used for security tasks: vulnerability discovery, exploit reproduction, and patch generation. Improving them at the model level demands expert demonstrations or computable rewards, which security tasks rarely offer: traces are costly, failures hard to diagnose, rewards sparse, and non-computable. Efforts thus shift to the harness and context, but manual tuning needs task-specific expertise and scales poorly, while automated methods rely on scarce ground truth, stronger optimizer models, or unguided propose-and-evaluate loops that reduce to costly trial and error.   We introduce SelfOp, an algorithm that automatically improves a frozen security agent's task context (instructions, skills, and reference documents), without modifying its execution harness and model weights. SelfOp casts context optimization as chain-rule-inspired textual gradient descent: from a single instance's outcome, it propagates error signals backward through the evaluator, the agent's trajectory, and the context artifacts that shaped its behavior, yielding per-instance textual gradients. Gradients are accumulated across instances by clustering, ranking, and filtering, and committed only under cross-instance consensus. A convergence detector monitors the gradient signal itself and stops once the context has absorbed the generalizable information in the training data, without held-out validation data.   We evaluate SelfOp on CyberGym, a benchmark of real-world vulnerability reproduction tasks. With fewer than 200 training examples, SelfOp yields a 17-point self-improvement for GPT-5.4-mini (with Codex), enough to surpass the frontier GPT-5.4 baseline by 6 points, and an 18.5-point self-improvement for GPT-5.4 itself. The optimized skills also transfer across models, highlighting that SelfOp-optimized skills learn generalizable task knowledge not model-specific patterns.

## 1. 论文的核心问题与整体含义

- **研究背景**：LLM 智能体在漏洞发现、漏洞复现、补丁生成等安全任务中表现突出，但要让智能体在新任务/新领域上持续改进，通常有三个抓手：训练更好的模型、优化执行框架（harness）、优化任务上下文（context）。
- **核心困难**：
  - **模型训练**需要专家演示、可计算奖励和大量受控环境，而安全任务中成功轨迹昂贵、失败难以诊断、奖励稀疏且往往不可计算。
  - **手工调优 harness 或上下文**需要领域专家，扩展性差。
  - 已有自动化上下文优化方法多采用单次分析、依赖留出验证集、依赖强优化器模型或规范解，且难以直接处理长时间、多步、工具调用的安全智能体轨迹。
- **整体含义**：SelfOp 试图回答“一个冻结的智能体能否仅利用任务数据、不修改模型权重和执行框架、也不依赖更强教师模型，就能自我改进其上下文”的问题。它把上下文优化系统化为一种“文本梯度下降”算法，在不改变模型的条件下提升安全智能体的漏洞 PoC 生成能力。

## 2. 论文提出的方法论

SelfOp 的核心思想是把智能体上下文（技能 `SKILL.md` 与参考文档）视为可学习参数 \(\theta\)，把任务执行与反馈过程类比为前向/反向传播，四个主要组件如下：

- **链式法则式梯度计算**
  - 将误差信号按因果链反向分解为：
    \[
    \frac{\partial L}{\partial \theta_{skill}}
    =
    \frac{\partial L}{\partial s}
    \cdot
    \frac{\partial s}{\partial \tau}
    \cdot
    \frac{\partial \tau}{\partial \theta_{skill}}
    \]
    其中 \(L\) 为二值损失，\(s\) 为评估分数，\(\tau\) 为智能体轨迹。
  - **Stage 1（\(\partial L/\partial s\)）**：把整体成功/失败分解为具体评估标准，定位失败发生在哪一步。
  - **Stage 2（\(\partial s/\partial \tau\)，skill-blind）**：在不看当前技能的前提下，结合漏洞元数据 \(\mu_v\) 重建漏洞的结构不变量 \(\hat\phi_v\)，分析轨迹中的行为强项与弱点，避免被现有上下文“锚定”。
  - **Stage 3（\(\partial \tau/\partial \theta_{skill}\)，skill-aware）**：将行为问题归因到具体技能内容（缺失或表述不当），并提出针对性修改。
  - 消融表明，完整三阶段链（D4，主优化器看到全部中间梯度）优于单次分析（D1）、每任务单阶段分析（D2）和只看最终阶段（D3）。

- **梯度累积**
  - 从每个任务的梯度中抽取原子化的“优势主题”和“改进主题”，再用 LLM 对跨任务主题进行聚类。
  - 用支持率（support ratio）和结果关联权重（outcome weight）计算综合得分，按阈值过滤，只保留跨任务一致的主题。
  - 对幸存改进主题进行**覆盖标注**：若技能完全未涉及该失败模式，标记为 **hard gradient（gap）**，允许新增内容；若技能已有指令但执行不力，标记为 **soft gradient（covered）**，只允许强化/改写已有内容。
  - 这种 hard/soft 区分用于校准更新“力度”，抑制无方向的内容膨胀。

- **收敛检测**
  - 观察 hard 梯度占比随优化步骤的变化：早期多为 gap，后期多为 covered。
  - 将 hard 梯度比例 \(\hat p\) 与噪声底限 \(p_0\) 比较，计算 z 分数；如果连续三步 z < 1.0，则认为残差梯度与噪声不可区分，自动停止，无需留出验证集。
  - 实验显示该信号式停止点达到 55% 测试准确率，优于验证集选点的 51%，且接近 oracle 最优 56.2%。

- **漏洞元数据监督**
  - 利用漏洞描述、补丁提交、sanitizer 堆栈等元数据 \(\mu_v\) 重建结构不变量 \(\hat\phi_v\)，让优化器在没有规范解、没有更强教师的情况下进行自我评估。

## 3. 实验设计

- **数据集与 benchmark**：
  - 使用 **CyberGym**：真实世界漏洞复现任务基准，任务是从漏洞描述生成能触发漏洞的 PoC。
  - 从 CyberGym 的 1,507 个实例中抽取约 23%：**224 个训练任务**、**40 个验证任务**、**80 个测试任务**，共 344 个。
  - 评估采用确定性的 sanitizer 输出与跨版本差分测试，得到二值 pass/fail 信号，避免 LLM 评判噪声。

- **智能体与优化器**：
  - 冻结的 harness 为 OpenAI Codex，底层模型主要是 GPT-5.4-mini；优化器同样使用 Codex + 同一模型，即不依赖更强教师。
  - 可学习参数限定为名为 `poc-generation` 的单个技能（`SKILL.md` + 参考文档），不涉及子智能体规范或可执行脚本。
  - 初始技能来自 CyberGym 基础提示。

- **训练设置**：
  - 批量大小 \(m=16\)，每个任务最多 30 分钟，评估为 pass@1。
  - 优化器在多个步骤间保持记忆，能回顾先前编辑及其效果。

- **对比方法**：
  - 设计四种梯度分解变体：D1 单次批量分析、D2 每任务单阶段、D3 链式但只看最后阶段、D4 链式并看全部阶段。
  - 对梯度累积阈值做三档消融：loose、slightly strict、strict。
  - 对覆盖标注做有无对比。
  - 与验证集选点、oracle 测试集选点对比收敛检测。
  - 额外研究：批量大小翻倍（32）、去掉漏洞元数据、扩展到 GPT-5.4、技能跨模型迁移。
  - 论文讨论中提到 ACE、MCE 等方法直接运行会过拟合单一参考 PoC，因此只保留其原始优化算法并供给相同元数据监督，将其核心设计映射为 D1/D2 对比点。

## 6. 主要结论与发现

- **链式分解优于单次分析**：D4 达到 48% 测试准确率，比 D1/D2/D3 有 7–9 点优势；同时 D3/D4 在 128 个训练样本时即达到 D2 用 224 个样本才达到的验证表现，样本效率提升 1.75 倍。
- **梯度累积 + 覆盖标注有效**：loose 阈值 + 覆盖标注最终测试准确率 51%，显著高于无累积的 48% 和更严格阈值的 42%/35%；hard/soft 标注使优化能持续到步骤 11，而不是在步骤 6–8 后退化。
- **信号式收敛检测优于验证集选点**：检测器停在步骤 8，测试准确率 55%，高于验证集选点的 51%，仅比 oracle 低 1.2 点，且不额外消耗前向评估。
- **总体性能**：
  - GPT-5.4-mini 从 38% 提升到 55%（+17 点），超过 GPT-5.4 基线 49%；
  - GPT-5.4 从 49% 提升到 67.5%（+18.5 点）；
  - 无元数据时仍从 36% 提升到 45%，加元数据再提升 11 点，说明算法与元数据监督均有独立贡献。
- **技能可迁移**：GPT-5.4 优化出的技能将 GPT-5.4-mini 提升到 65%，GPT-5.4-mini 的技能将 GPT-5.4 提升到 62%，说明学到的是通用任务知识而非模型特有模式。
- **批量大小敏感**：批量大小翻倍到 32 会令测试准确率降至 35%，跨主题共识被稀释为过于泛化的建议。

## 7. 优点

- **方法设计有明确的问题导向**：针对安全任务缺乏规范解、验证集昂贵、单次分析不可靠、上下文膨胀等具体痛点逐层设计组件。
- **链式法则分解直观且有效**：特别是 Stage 2 的 skill-blind 阶段，先独立重建漏洞不变量，再归因到技能，避免“以现有技能为锚”的偏差。
- **无需更强教师模型**：优化器和智能体使用同一模型，实现真正的“自我改进”。
- **hard/soft 覆盖标注**：将“缺失内容”和“已有但未执行”区分开来，有效控制文本参数更新的方向和幅度，防止无方向上下文增长。
- **无验证集的收敛检测**：利用梯度信号自身判断收敛，大幅减少前向评估开销，对昂贵安全任务尤其有实际价值。
- **漏洞元数据监督**：将补丁、描述、堆栈等已有信息转化为结构不变量，缓解规范解缺失带来的捷径学习风险。
- **跨模型迁移实验**：表明优化产物是任务知识而非模型专用提示，增强了结果的可泛化性。

## 8. 不足与局限

- **单一 benchmark 与任务类型**：只在 CyberGym 的漏洞 PoC 生成任务上验证，未在补丁生成、漏洞发现、利用生成等其他安全任务或数据集上评估。
- **数据规模受限**：仅使用约 23% 的 CyberGym，训练仅约 15%，主要原因是 API 执行成本高昂；这限制了对更广泛漏洞类型的结论外推。
- **仅覆盖文本上下文参数**：可学习参数限于 `SKILL.md` 和参考文档，未扩展到子智能体规范、可执行脚本或 harness 配置；论文虽讨论了扩展方向，但未经实验验证。
- **对比方法非完全原始实现**：ACE/MCE 等直接运行会失败，因此是“保留其算法但更换监督信号”的适配比较，不能完全代表原方法在原始条件下的表现。
- **单智能体/harness 与单模型为主**：主要使用 GPT-5.4-mini + Codex，对其他模型和 harness 的组合验证有限。
- **批量大小敏感**：batch size 从 16 增到 32 造成明显性能下降，表明方法对超参数较敏感。
- **pass@1 与非确定性**：只报告单次运行能力，虽然误差带内的结论仍成立，但未能给出 pass@k 等更稳健指标。
- **成本与可复现性**：实验成本高，且未提供 GPU 资源细节，可能影响其他团队完全复现完整流程。
