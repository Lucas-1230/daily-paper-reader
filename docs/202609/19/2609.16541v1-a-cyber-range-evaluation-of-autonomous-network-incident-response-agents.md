## 摘要
我们在一个用于人类操作员训练的网络靶场中测试了用于自动化网络入侵响应的智能体的性能。该靶场实现了一个仿真网络环境，具有可变网络拓扑、红队模拟和模拟用户代理。防御智能体的目标是阻止红队智能体访问网络中的主机，同时最小化防御措施带来的可用性代价。警报通过SIEM平台生成，并映射到智能体使用的数据建模语言。我们测试了启发式智能体和通过强化学习学到的策略的组合。所学策略通过一个对网络建模的网络攻击模拟器进行优化，以最小化综合代价。我们发现，强化学习智能体在防御系统方面总体上比启发式策略更高效，并且其性能高度依赖于对手策略与模拟用户的结合。

## Abstract
We test the performance of agents for automated network intrusion response in a cyber range intended for human operator training. The range implements an emulated networking environment with a variable network topology, red-team emulation and simulated user agents. The goal of the defensive agents is to prevent hosts in the network from being accessed by the red-team agent, while minimizing the availability costs induced from defensive measures. Alerts are generated using a SIEM platform and mapped to a data modeling language used by the agents. We test a combination of heuristic agents and policies learned using reinforcement learning. The learned policies are optimized to minimize the combined cost using a cyber attack simulator modeling the network. We found that the reinforcement learning agents were overall more efficient at defending the system than the heuristic policy, and that the performance depends highly on the policy of the adversary in combination with the simulated users.

## 1. 论文的核心问题与整体含义

- **研究背景**：网络攻击与安全事件频繁发生，快速缓解攻击对于避免敏感信息泄露和关键系统瘫痪至关重要。目前网络入侵响应主要依赖人工操作员或规则型自动化系统。
- **核心问题**：强化学习（RL）驱动的自主防御智能体是否能在真实的、面向人类训练的网络安全靶场中，比手工设计的启发式策略更高效地完成网络入侵响应任务，同时在安全性与系统可用性之间取得更好平衡。
- **整体含义**：以往大多数 RL 网络防御代理仅在模拟器中被评估，缺少在真实目标系统中的验证，存在“sim-to-real”鸿沟问题。本研究将 RL 代理部署到包含 37 台虚拟机的网络靶场（ADS-24）中，与红队仿真工具 Lore 进行 2 小时的真实网络对抗，验证 RL 方法在 cyber range 环境中的可行性和优势。

## 2. 论文提出的方法论

- **防御任务建模**：将问题形式化为**部分可观测马尔可夫决策过程（POMDP）**，其中防御代理需要最小化由**攻击代价**（保密性+完整性）和**防御代价**（可用性）构成的综合代价函数。
- **系统与数据建模**：使用 **Meta Attack Language（MAL）** 创建网络系统模型，定义了包含 9 种资产类型、49 个攻击步骤和 2 个防御步骤的简化语言 **CadsLang**。网络状态被表示为二部因子图，攻击步骤和防御步骤均以资产为节点。
- **代理实现与训练**：使用 **Vejde** 强化学习框架，该框架支持关系型状态空间和基于消息传递的图神经网络（GNN）。训练在 **MAL Simulator** 中进行，采用 PPO（Proximal Policy Optimization）算法，共使用 200 万步转移样本。训练环境包含不同攻击者策略、入口点和拓扑变化，以增强策略的泛化能力。
- **从模拟到真实（sim-to-real）**：在实际网络评估中，通过 Osquery 收集主机数据构建 MAL 实例模型；Wazuh 事件通过一组规则映射到 CadsLang 攻击步骤，构成代理的观测数据库；代理产生的防御步骤被映射回 Wazuh Active Response 命令（关机或网络隔离）并在主机上执行。
- **代价函数公式**：每个时间步的代价定义为
  \[
  r(t) = \sum_{A(t)}[C(x) + I(x)] + \sum_{D(t)}A(x)
  \]
  其中 \(A(t)\) 表示已执行的攻击步骤集合，\(D(t)\) 表示已激活的防御步骤集合，\(C, I, A\) 分别代表资产的保密性、完整性和可用性权重。整个回合的回报为 \(R = \sum_t r(t)\)。

## 3. 实验设计

- **实验环境**：目标网络为 37 台虚拟机的 ADS-24，包含 CLIENT、DMZ、SRV、SOC 四个子网。红队由 **Lore** 仿真，分**Guided（引导式）** 和 **Exploratory（探索式）** 两种策略；模拟用户代理执行邮件、远程桌面等日常活动。
- **防御代理对比**：
  - **Vejde**：在 MAL Simulator 中用 RL 训练的策略；
  - **Vejde w/ Noise**：训练时在观测层加入 1% 假阳性/假阴性噪声的 RL 策略；
  - **Heuristic**：观察到攻击步骤后立即执行相应防御动作的规则策略；
  - **NoOp**：不采取任何行动的基线。
- **场景变量**：有无模拟用户、Lore 策略类型（Guided / Exploratory）、网络拓扑随机减除主机（rootca、timereporter、print）。
- **评估指标**：主要指标为 2 小时回合的总回报（即总代价），同时区分攻击代价与防御代价。每组代理约 30 个 episode，共计 134 个 episode。

- **充分性分析**：

## 6. 主要结论与发现

- **RL 代理整体更高效**：Vejde w/ Noise 在所有评估条件下获得了最高的平均回报，主要因为其防御代价大幅低于 Vejde 和 Heuristic。
- **性能高度依赖对手策略**：当 Lore 采用 Guided 策略（只沿最快路径攻击）时，NoOp 反而获得了最高的平均回报，因为 Lore 本身没有造成大量损失，任何防御动作都会增加不必要的可用性代价；而面对 Exploratory 策略时，RL 代理的防御优势才体现得更明显。
- **模拟用户的影响**：模拟用户产生的假警报会使所有决策代理的回报下降，其中在面对 Guided 策略时下降最为显著（−80% 到 −109%），主要是防御代价上升。
- **Vejde 攻击代价最低但防御代价最高**：Vejde 在阻止 Lore 行动方面最有效果，但付出了极高的可用性代价。
- **敏感度分析**：通过调整攻击与防御代价的权重，发现在当前权重设置下，除非攻击代价相对约提高 30%，否则任何防御代理都不如“不做任何事”（NoOp）；而在 Exploratory 策略下，即使攻击代价降低 30%，RL 代理仍优于 NoOp。

## 7. 优点

- **高保真评估**：工作部署在面向人类操作员的真实网络靶场中，使用了真实的 SIEM（Wazuh）、真实的红队工具（Lore）、真实的用户模拟器，以及虚拟化主机，显著提高了实验的生态效度。

- **多维度评测**：同时考察了攻击代价与防御代价，引入了攻击者策略、用户行为和拓扑变化三个关键的泛化测试维度。

## 8. 不足与局限

- **统计效力不足**：每个代理 × 场景组合的 episode 数量较少，Vejde w/ Noise 的方差很大，导致部分结论不够稳健。
- **评估网络单一**：只在一个网络拓扑（ADS-24）中进行了评估，拓扑变化也只涉及三个非关键主机，无法充分证明代理的跨拓扑泛化能力。
- **假阳性分布建模偏差**：模拟器中的假阳性率被假设为均匀分布（1%），但在真实网络中不同攻击步骤的假阳性率差异很大（如 attemptConnectToApplications 为 10–17%）；这可能是导致 RL 代理在真实环境中防御代价偏高的原因之一。
